Aulosyne custom themes

Choose a look.
Make it yours.

Pick a theme below, copy its import string, then paste it into Aulosyne. No downloads or extra files are needed for the theme itself.

How to use a theme

Four quick steps inside Aulosyne.

1

Choose a theme

Find the theme you want below and click Use theme.

2

Copy the string

A theme import string will appear. Click Copy string.

3

Open Customisation

Open Aulosyne → Settings → Customisation → Import.

4

Paste & import

Paste the copied string into the import box, then tap Import.
